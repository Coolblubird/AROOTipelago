# AROOTipelago
An APWorld for playing ROOT: a Woodland Game of Might and Right on Archipelago using campaign rules I've made called "CATS," which you can find here: https://docs.google.com/document/d/12y8dlnfEjgPmX1IYp7vI9YlP9EN-ISOFOHOyHCbKBm8/edit?tab=t.0

Unfortunately, at this time it will only support Marquise De Cat as playable, since it is the easiest faction to balance around, but I am open to other militant factions (and *maybe* some of the others, but they would need a lot more work to get a campaign to be fun).

However, since this is a manual, if you want a friend to join, they can simply play the other faction you are fighting against, as long as they understand that you will grow stronger and stronger as the campaign progresses.
